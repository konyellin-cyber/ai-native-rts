# Phase 27 Art Pipeline

This folder stores the Phase 26 soldier art pipeline rehearsal.

Folder roles:

- `prompts/`: exact prompts and revision notes.
- `references/`: input reference images copied into the repo.
- `outputs/`: generated images selected for review or validation.
- `reviews/`: step-by-step quality reviews.

Rule: every generated image used by this phase must have a prompt record and a review record.
