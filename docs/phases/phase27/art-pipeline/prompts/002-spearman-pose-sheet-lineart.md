# 002 Spearman Pose Sheet Lineart

## Goal

Use the accepted perspective construction base from Step 1 to create a Phase 26-style spearman frame animation pose sheet.

This step validates whether several animation key poses can keep the same 45-degree RTS perspective, body proportion, foot placement logic, and spear ground-plane direction. It must remain a construction-line / sketch sheet, not finished art.

## Positive Prompt

Using the visible reference image as the strict perspective and proportion base, create a clean pencil/ink construction pose sheet for a single medieval spearman in a 45-degree orthographic RTS camera.

Keep from the reference:
- same non-heroic body proportion
- same top-down 45-degree RTS camera
- visible helmet/top-of-head direction
- visible shoulders and torso top plane
- feet placed clearly on an isometric ground plane
- long spear aligned to the same ground-plane direction
- construction drawing style with black, gray, and light blue guide lines

Create exactly six key poses in a neat 3x2 grid:
1. idle ready
2. march step
3. brace / hold line
4. thrust attack
5. hit stagger
6. fallen

For every pose:
- show simple body construction forms: head sphere, chest box, pelvis block, limb cylinders, joint marks
- show small ground-plane guide lines or an ellipse under the feet/body
- keep the same body scale and camera angle
- keep the spear as a simple construction line, not a finished rendered weapon
- preserve clear foot contact points
- leave generous spacing between poses

Style:
- rough but readable animation production sketch
- line art only
- white or very light gray paper background
- no color fill
- no material rendering
- no shadows
- no labels
- no watermark

## Negative Prompt

Avoid finished colored art, detailed armor, rendered materials, shadows, side-view sprites, front-facing pose sheet, horizontal brawler animation, perspective camera distortion, inconsistent body size, inconsistent spear length, missing ground guides, cropped feet, cropped spear, text labels, UI, watermark, scenery, multiple different characters.
