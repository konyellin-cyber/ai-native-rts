# 002 Spearman Pose Sheet Lineart V2

## Goal

Improve the first pose sheet using the accepted perspective construction base.

This revision focuses on:

- lower front-rank spear-wall posture
- more consistent spear tip direction
- less body-size drift between frames
- clearer 45-degree ground-plane relationship

It must remain construction line art only.

## Positive Prompt

Using the visible reference perspective construction image as the strict camera and proportion master, create a revised pencil/ink construction pose sheet for one medieval spearman in a 45-degree orthographic RTS view.

Keep exactly the same visual logic as the reference:
- same top-down 45-degree orthographic RTS camera
- visible top of helmet, shoulders, chest top plane, pelvis block
- same grounded non-heroic mass-soldier proportions
- feet clearly placed on a small isometric ground grid or ellipse
- spear lies on the same diagonal ground-plane direction in every standing pose
- black and gray body construction lines with light blue perspective guide lines
- line art only, no color fill, no shadows, no material rendering

Create exactly six poses in a neat 3x2 grid:
1. idle ready: upright but grounded, spear diagonal on ground plane
2. march step: same body scale, one foot advancing, spear still diagonal
3. brace / hold line: lower stance, knees bent, torso leaning forward slightly, spear leveled toward the same battle-line direction
4. thrust attack: forward extension from the brace pose, spear tip aligned with the same direction
5. hit stagger: body recoils but feet and ground relation remain clear
6. fallen: body on the ground, still in the same camera angle, not oversized compared with the standing frames

For every pose:
- use construction forms: head sphere, chest box, pelvis block, limb cylinders, joint circles
- preserve consistent head size and torso size
- preserve consistent spear length
- show foot contact marks
- keep the character facing the same diagonal direction
- leave generous spacing between frames

Style:
- rough animation production sketch
- clean readable construction drawing
- white or very light gray paper background
- no labels and no text
- no watermark

## Negative Prompt

Avoid finished art, color rendering, detailed armor, side-view sprites, front-facing character sheet, horizontal brawler animation, dramatic perspective, inconsistent body sizes, inconsistent spear length, random spear directions, missing ground guides, cropped spear, cropped feet, text labels, UI, scenery, multiple different characters, shadows, painterly detail.
